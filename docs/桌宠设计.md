# FocusFish 桌面大肥鱼 · 设计文档

> 目标：把 dsh-pet（DeepSeek Harness 生态的桌宠插件，5.5k★ MIT）的桌面体验，
> 复刻到 Android 上，让蓝色大肥鱼**常驻手机桌面**。

---

## 一、要复刻的是什么

### dsh 是什么

**dsh = DeepSeek Harness**，DeepSeek 官方开源的 agent 运行时（基于 Cordis，一切皆插件）。
官方有 Windows / macOS 桌面端（Electron）与浏览器端，插件用
`dsh plugin --profile desktop add <包名>` 安装。

**桌宠不是独立产品，而是生态里的一类插件。** 主力是
[`dsh-pet`](https://github.com/PC2005-cloud/dsh-pet)（PC2005-cloud，5.5k★，MIT），
形象正是**鲸鱼娘·大肥鱼**（DeepSeek 蓝鲸 logo 的社区二创 OC）。

生态规模：`dsh-plugin` topic 下 2.7 万个公开仓库，官方称第三方插件约 3.5 万个。

### 桌宠的核心体验

| 交互 | 反应 |
|---|---|
| 单击 | Q 弹挤压形变 + 随机回应动画（开心/害羞/傲娇）+ 台词气泡 |
| 按住拖动 | **弹簧跟手**（不是硬贴），拖动时侧身朝向拖动方向，松手说话 |
| 快速甩出 | 抛物线飞行，撞屏幕边缘反弹，落地摩擦减速 + 晃悠站稳 |
| 自主散步 | 沿屏幕底部横向行走，头朝移动方向，走到边界掉头，**不跑出屏幕** |
| 贴边躲藏 | 拖到边缘自动贴上，静置 12 秒缩进去只露半个身子，碰一下探出 |
| 闲置随机动作 | 待机呼吸、打瞌睡、玩魔方、吃火锅、吐泡泡、写代码、抱玩偶 |
| 睡觉 | 睡下后完全安静，周期冒梦话，点它或右键「起来」醒 |
| 碎碎念 | 周期自动说一句，**20 秒冷却**，按 11 类情境分（开机/被连点/被甩/贴边/早晚/久置） |
| 对话 | 点气泡/图标弹出聊天面板，接 DeepSeek API |
| 喂食 | 双击开喂食面板 → 吞咽动画 + 满足表情，饱食度/亲密度成长 |
| 工作状态联动 | 跟随会话在思考/工作/整理/等待/成功/出错六档切动画 + 头顶气泡 |
| 余额 | 每 20% 一档，越少越慌（钱袋满溢→金袋叮当→数金皱眉→分文不剩） |

### 视觉规格

- 手绘 Q 版贴纸风（SVG 贴纸为主，非 Live2D）
- 透明、无边框、无底座、置顶；默认落右上角
- 素材是 **VP9-Alpha WebM** 视频动画（安卓移植版 91 段）
- 气泡在头顶，白色毛玻璃，跟随宠物移动
- 物理参数：弹簧 K=200、C=30、重力 1400、落地恢复 0.78、地面摩擦 2.5
- 尺寸 80–360dp；帧率 50fps（性能）/ 25fps（休闲）

## 二、Android 上的技术选型

### 三条路线的取舍

| 路线 | 权限 | 能做到什么 | 致命限制 | 结论 |
|---|---|---|---|---|
| **Overlay 悬浮窗** | `SYSTEM_ALERT_WINDOW`（特殊权限）+ 前台服务 | 任意应用之上常驻、可拖、可抛物理、有气泡、锁屏仍在 | 后台必须挂前台服务；厂商 ROM 需额外白名单 | ✅ **唯一正解** |
| Live Wallpaper | 几乎为零 | 桌面全屏、帧率稳 | **切到任何 App 立刻消失** | ❌ 自毁陪伴 |
| AppWidget | 无 | 桌面一格常驻 | RemoteViews 不支持自定义 View / Animator，物理抛掷做不到 | ❌ 只适合功能型小部件 |

**为什么 Live Wallpaper 不行**：社区差评第一是「打开别的 App 鱼就没了」。
而陪伴的价值恰恰在「你不在时它也在」——
鱼在你不专注的时候陪着你，在你摸鱼的时候提醒你，那才是陪伴。

**为什么 Overlay 是正解**：它是唯一能让大肥鱼出现在**其它 App 之上**的方式。
用户用微信摸鱼时它飘在微信右上角喊一句「你今天摸鱼有点久哦」，
这才是 dsh-pet 的核心场景。

### 安卓移植的关键工程决策

**Android MediaCodec 原生不支持 VP9 alpha** —— 这是 dsh-pet 安卓移植版绕不开的坑。
社区方案是**旁路 alpha**（side-by-side：左边色彩、右边灰度 alpha，用 shader 合成）。

**FocusFish 的应对**：我们不用 alpha 视频。
现有素材是**白底 PNG/WebP**，做法是：

1. **抠白底** → 输出带 alpha 的 PNG（用 ffmpeg 的 `colorkey` 滤镜或直接用白底图的 alpha 抠图）
2. 桌宠用 **`ImageView` + `AnimatedImageDrawable`** 播放 **animated WebP**（Android 原生支持，带 alpha）
3. 若视频素材需要，转成 **animated WebP**（`-c:v libwebp_anim`），同样支持 alpha

这样既绕开 VP9-alpha 的坑，又不用引入 GLSurfaceView + MediaCodec 的复杂度。

### 权限清单

| 权限 | 用途 | 必要性 |
|---|---|---|
| `SYSTEM_ALERT_WINDOW` | 悬浮窗显示 | 必需（跳系统设置页授予） |
| `FOREGROUND_SERVICE` + `FOREGROUND_SERVICE_SPECIAL_USE` | 桌宠前台服务 | 必需（Android 14+ 强制声明类型） |
| `POST_NOTIFICATIONS` | 前台服务通知 | Android 13+ 必需 |
| `RECEIVE_BOOT_COMPLETED` | 开机自启 | 可选 |
| `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | 电池优化白名单 | 强烈建议（防被杀） |

### 厂商 ROM 注意事项

| ROM | 需要额外开 |
|---|---|
| MIUI / HyperOS | 「后台弹出界面」+ 电池策略「无限制」+ 自启动 |
| ColorOS / OPPO / 一加 | 「允许后台运行」+ 自启动 |
| MagicOS / 荣耀 | 「允许后台活动」+「应用启动管理」白名单 |
| EMUI / HarmonyOS | 「应用启动管理」→ 手动管理 → 允许自启动 |

**Android 15 起**：光有 SAW 权限还不够，起前台服务前必须先有可见的叠加层。
→ 所以桌宠服务必须在用户**主动开启桌宠**时启动（此时有可见 Activity 上下文），
而不是靠后台自启。

## 三、FocusFish 桌宠设计

### 3.1 架构

```
┌─────────────────────────────────────────────┐
│  DesktopPetService (前台服务, SPECIAL_USE)    │
│                                              │
│  ├─ PetWindowController                      │
│  │   └─ WindowManager.addView                │
│  │       ├─ PetBubbleView   (台词气泡)        │
│  │       └─ PetSpriteView   (大肥鱼本体)       │
│  │                                            │
│  ├─ PetBrain  ──→ 读取 FishStateEntity        │
│  │   │            好感度/饱腹/精力/心情        │
│  │   └─→ 决定当前表情 + 是否主动冒泡          │
│  │                                            │
│  └─ PetPhysics (物理引擎)                     │
│      ├─ 弹簧跟手                              │
│      ├─ 抛物线 + 边缘反弹                      │
│      └─ 地面摩擦减速                          │
└─────────────────────────────────────────────┘
              ↓
        LocalLineLibrary (零 token 台词)
              ↓
        AI 主动开口（可选，走 ProactiveEngine）
```

### 3.2 状态机

大肥鱼桌宠有 7 种状态，每种对应不同的动画与行为：

```
        ┌──────────┐
        │   IDLE   │ 待机呼吸，偶发碎碎念
        └────┬─────┘
             │ 点击 / 拖动 / 抛掷
     ┌───────┼────────┬─────────┐
     ▼       ▼        ▼         ▼
  ┌──────┐┌──────┐┌──────┐ ┌────────┐
  │TAPPED││DRAG  ││FLUNG │ │ WALKING│ 散步
  └──────┘└──────┘└──────┘ └────────┘
     │       │       │         │
     └───────┴───────┴─────────┘
                 │ 抛掷落地后
                 ▼
           ┌──────────┐
           │  HIDDEN  │ 贴边缩进，只露半个身子
           └──────────┘

  ┌────────┐  右键/长按「睡觉」  ┌────────┐
  │ SLEEPING│ ←──────────────→ │  AWAKE │
  └────────┘                    └────────┘
```

### 3.3 交互清单（FocusFish 版）

| 交互 | 反应 | 实现要点 |
|---|---|---|
| **单击** | Q 弹挤压（scaleX 1.2 / scaleY 0.8 → 回弹）+ 随机表情 + 台词气泡 | 弹簧动画，200ms |
| **双击** | 打开喂食面板 | 复用 App 内的投喂逻辑 |
| **按住拖动** | 弹簧跟手（K=200, C=30），侧身朝向拖动方向 | 不用硬贴，跟手要有迟滞感 |
| **松手** | 抛物线落下（重力 1400）+ 落地反弹 0.78 + 摩擦 2.5 | 落地后晃悠站稳 |
| **快速甩出** | 明显抛掷，撞屏幕边缘反弹 | 速度超阈值触发 |
| **点击气泡** | 打开聊天页 | 启动 MainActivity 带路由 |
| **长按** | 弹出菜单：回家 / 睡觉 / 隐藏 / 退出 | 用 PopupWindow |
| **自主散步** | 沿屏幕底部走，走到边界掉头 | 头朝移动方向（水平翻转） |
| **贴边** | 拖到边缘自动贴上，静置 12 秒缩进去只露半个身子 | 碰一下探出 |
| **闲置随机动作** | 呼吸 / 眨眼 / 偶尔换个表情 | 每 30 秒切一组 |
| **睡觉** | 完全安静，只偶尔冒梦话 | 睡下时所有主动行为拦掉 |

### 3.4 台词气泡

**双轨设计**（这是调研里最关键的一条反面经验）：

| 模式 | 触发 | token 消耗 |
|---|---|---|
| **本地陪伴** | 待机、点击、拖拽、散步、贴边 | **0** |
| **AI 陪伴** | 主动开口、聊天 | 走 API |

- 本地台词来自 `LocalLineLibrary`（已有的 48 句）
- AI 模式失败时**必须有兜底台词**，不能让大肥鱼消失
- 气泡可一键关闭
- 气泡 10 秒自动收起（工作状态气泡按 dsh 规则 10 秒收起）

### 3.5 与 App 内状态的联动

桌宠读的是**同一份 `FishStateEntity`**，所以：

| App 内状态 | 桌宠表现 |
|---|---|
| 饱腹度 < 25 | 换成 hungry 表情，偶发「……本鲸的白饭呢」 |
| 精力 < 20 / 正在睡 | 换成 sleeping 表情，闭眼 |
| 心情低落 | 换成 sad 表情，动作幅度变小 |
| 好感度高 | 主动搭话频率略升（命中线 +5） |
| 正在专注 | **不主动说话**，只安静陪读（读书动画） |
| 刚喂过 | 换成 proud 表情，「嘿嘿」 |

这条联动是 FocusFish 相对 dsh-pet 的**独有优势**：
dsh-pet 的状态靠「余额」这一个维度，FocusFish 有四维状态 + 真实的使用数据。

### 3.6 尺寸与位置

- 默认尺寸 **160dp**（可调 80–280dp）
- 默认位置：右上角，距顶 120dp、距右 16dp
- 可拖到任意位置，位置持久化
- 「点穿透」开关：开启后只响应头部小热区，避免挡内容

## 四、反面清单（做砸了会怎样）

1. **别做 Live Wallpaper** —— 用户第一差评就是「打开别的 App 鱼就没了」。
   反过来选了 Overlay，就必须把「被系统杀后台」当一级风险：
   前台服务 + 电池白名单引导 + 隐藏后台，全套都要做。
   用户会说「软件坏了」，不会说「系统杀的」。

2. **素材别贪多** —— dsh-pet 安卓包 63–79MB 是真实教训。
   而且 91 段动画里用户只会记住 3–5 个。
   **先把「待机 + 点击反馈 + 拖拽 + 睡觉」做到极致，再扩库。**

3. **台词是双刃剑** —— 必须自带冷却、按情境分类、可一键关气泡、可编辑。
   吵一点就翻车。

4. **遮挡 / 误触 / 抢焦点是三大差评源** ——
   `FLAG_NOT_FOCUSABLE` 不抢键盘；提供点穿透；提供缩小/贴边/隐藏；
   全屏游戏时自动隐藏。

5. **「AI 味」和「不 AI」都会被骂** —— 本地陪伴模式与 AI 陪伴模式显式分离，
   AI 失败时桌宠必须有兜底台词而不是消失。

### P5 的素材需求

桌宠本体用 **animated WebP**（白底抠成透明），规格：

| 项 | 要求 |
|---|---|
| 尺寸 | 512×512 |
| 帧数 | 24–48 帧 |
| 时长 | 2–4 秒，循环 |
| 背景 | 透明（抠白底） |
| 动作 | 待机呼吸 / 行走 / 睡觉 / 开心 |

生成方式：可灵 / 即梦「图生视频」→ ffmpeg 转 animated WebP + 抠白底。

```powershell
ffmpeg -y -i 原始.mp4 -vf "colorkey=white:0.3:0.1,scale=512:512" `
  -c:v libwebp_anim -lossless 0 -quality 75 -loop 0 输出.webp
```
