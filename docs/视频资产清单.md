## 二、还缺什么：`videos/focus/bigfatfish.mp4`

专注陪读视频是唯一还缺的一段。规格要求：

| 项 | 要求 |
|---|---|
| 时长 | **5~8 秒**（循环） |
| 尺寸 | 1080×1080（跟静态图同比例） |
| 背景 | **纯白 / 透明**，不要地面阴影 |
| 循环 | 首尾要能接上 |
| 动作 | 戴小眼镜、捧着书，安安静静看书，偶尔翻一页 |

### 提示词（可直接粘贴到可灵 / 即梦 / Vidu）

```
Same character. She wears small round reading glasses and holds an open book
with both flippers, quietly reading with focus, occasionally turning a page.
Calm and studious, soft cel shading, static camera, pure white background,
no shadow, no text, seamless loop
```

### 生成参数

| 工具 | 建议 |
|---|---|
| **可灵 (Kling)** | 「图生视频」模式，用 `assets/cats/bigfatfish.png` 当首帧参考图，运镜选「固定镜头」，时长 5s |
| **即梦 / Dreamina** | 图片首帧 + 「运镜：无」，4~6 秒 |
| **海螺 / Vidu** | 参考图模式，比例选 1:1 |
| **混元视频** | 首帧图 + 循环参数开 |

**关键**：一定要用**图生视频**而不是文生视频。
文生视频出来的蓝色大肥鱼跟手上的静态图长得完全不一样，一换 breedId 视觉就断了。

## 三、如果要重做现有视频

现有视频是从 B 站二创视频里剪的，已经统一处理过：

- 压缩到最大边 480、crf 28、去音轨、`faststart`（ExoPlayer 起播更快）
- 修剪掉空白开头，片段长度 7-10 秒
- 总量从 10.3 MB 压到 1.1 MB

如果你要用自己生成的视频替换，**建议规格**：

| 项 | idle | eating | focus |
|---|---|---|---|
| 时长 | 4~6 秒 | 3~5 秒 | 5~8 秒 |
| 尺寸 | 1080×1080 | 1080×1080 | 1080×1080 |
| 背景 | 纯白/透明 | 纯白/透明 | 纯白/透明 |
| 循环 | 要接上 | 单次播放 | 要接上 |

压缩命令：

```powershell
$ff = "ffmpeg.exe"
ffmpeg -y -i 原始.mp4 -vf "scale='min(480,iw)':-2" -c:v libx264 -crf 28 `
  -preset veryfast -pix_fmt yuv420p -movflags +faststart -an 输出.mp4
```

**首帧必须和 `assets/cats/bigfatfish.png` 的姿势接近** ——
App 的做法是「静态图先显示，视频 ready 后再切换」，首帧接近才能无缝。

## 五、如果没有视频会怎样

不会崩。App 有降级逻辑：

- 视频不存在 → 显示 `assets/cats/bigfatfish.png` 静态图 + 呼吸缩放动画
- eating 视频不存在 → 直接播静态图 + 上下浮动
- focus 视频不存在 → 专注页显示静态图

## 六、关于 3D 资产

调研结论（已核实）：

- **Sketchfab** 上有一个 `deepseek-big-fat-whale-yukkuri` 模型（10.4k 三角面），
  但它是 **CC BY-NC-SA 4.0**，禁止商用 → **不建议直接打包进 App**
- **MakerWorld** 有 83 个 deepseek tag 的模型，同样是 NC 授权
- **没找到**任何确认属于大肥鱼的 SD/LoRA/checkpoint

所以 3D 这条路**性价比很低**：要么授权有风险，要么得自己训练 LoRA。
**建议先不做 3D**，把视频 + 表情包这条线做扎实，3D 作为后续可选项。
